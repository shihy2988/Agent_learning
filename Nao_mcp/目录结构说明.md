## 二、启动与运行

### 入口 `mains/main_AQJC.py`

```python
from fastmcp import FastMCP
from tools.aqjc_tools import AQJCMcpService

mcp = FastMCP(
    "nao_aqjc_mcp_service",
    "A service to manage and query 安全监测系统测点和分站 database and statuses.",
)
AQJCMcpService(
    mcp=mcp,
    host="10.11.3.210", port=8123,
    database="PS_NAO", user="default", password="xt123456",
)
mcp.run(transport="http", port=7666, host="0.0.0.0")
```

启动方式：

```bash
cd /home/user/公共/shihy/Nao_mcp
python mains/main_AQJC.py
# 监听 0.0.0.0:7666，端点 /mcp（Streamable HTTP transport）
```

依赖：`fastmcp`、`clickhouse_connect`、`fuzzywuzzy`、`urllib3`。

## 三、核心模块说明

### 1. `tools/aqjc_tools/aqjc_tool.py`（核心，1480 行）

类 `AQJCMcpService`，`__init__` 时建立 ClickHouse 连接、实例化 `QyjcBase`，并依次调用
`_register_resources()` / `_register_prompts()` / `_register_tools()`。

| 注册项 | 装饰器 | 说明 |
|---|---|---|
| resource `docs://aqjc/data-dictionary` | `@mcp.resource` | 返回数据字典/字段说明/查询指南的 markdown |
| prompt `analysis_guide` | `@mcp.prompt` | 数据分析工作流指南（时间对齐→意图路由→参数构建→结果解释）|
| tool `get_system_time` | `@mcp.tool` | 返回服务器当前时间 + 星期 |
| tool `query_todayornow_points` | `@mcp.tool` | 今日/当前测点明细+统计 |
| tool `query_points_list` | `@mcp.tool` | 历史区间明细+统计 |
| tool `query_point_yb_info` | `@mcp.tool` | 测点异常/预警记录 |
| tool `query_station_status` | `@mcp.tool` | 分站运行/供电状态 |
| tool `query_station_point_tree` | `@mcp.tool` | 分站↔测点关联树/枚举 |

内部辅助：
- `_compact_station_status()`：分站状态两阶段压缩（摘要→极简），阈值 `MAX_JSON_SIZE=30000`
- `_compact_yb_info()`：异常记录压缩，阈值 20000
- 常量：`ABNORMAL_TYPE_MAP`（001~010 异常类型码映射）、`FILTERABLE_FIELDS`（numeric_filters 可筛字段）、
  `DEFAULT_STATS_TODAY/MULTI`（默认统计项）、`ALLOWED_POINT_FIELDS`/`ALLOWED_FZ_FIELDS`（tree 的 fields 白名单）

文件尾部有 `test_query_station_point_tree` 等本地自测 async 函数（`_pretty` 美化打印）。

### 2. `utils/aqjc_utils/aqjc_bases.py`（AQjcBase 基类，513 行）

DB 访问与数据处理封装，被 `AQJCMcpService` 持有为 `self.qyjc_base = AQjcBase(...)`：

| 方法 | 作用 |
|---|---|
| `get_fzdy_info(where)` | 分站基本信息 |
| `get_cddy_info(where)` | 测点基本信息 |
| `get_fz_status(realtime, where)` | 分站实时/历史状态 |
| `get_yb_info(point_code, start, end)` | 测点异常记录 |
| `_fetch_window_points(start, end, point_code)` | 取时间窗测点 |
| `_fetch_day_points(day, point_code)` | 取单日测点 |
| `get_points_daytype_with_cache(...)` | 按天/类型取测点（带缓存）|
| `point_filter(...)` | 测点条件过滤 |
| `start_auto_analysis_thread()` / `_run_daily_auto_analysis()` | 每日自动分析线程（SQLite 缓存 `aqjc_analysis_cache.db`，运行时惰性生成，近7天强制实时、更早走缓存）|

### 3. `utils/aqjc_utils/base_utils.py`（通用工具，245 行）

- `generate_statistics`：按字段做均值/中位数/标准差/最大最小等统计聚合
- `normalize`：数据归一化
- `fuzzy_match`：模糊匹配（配合 `fuzzywuzzy`，各工具不同阈值）
- `check_numeric_condition`：执行 `numeric_filters` 的 op 条件判断

### 4. `sqls/AQJC_sqls/`（ClickHouse SQL 层）

| 文件 | 导出函数 | 说明 |
|---|---|---|
| `base_info_sqls.py` | `query_fzdy_info` | 分站基本信息（1D/30D/2Y 表）|
| `base_info_sqls.py` | `query_cddy_info` | 测点基本信息（1D/30D/2Y 表）|
| `substation_sqls.py` | `query_fz_history` | 分站状态历史（状态岛/区间聚合）|
| `point_sqls.py` | `query_cd_realtime` | 测点实时时序（按天/测点分组）|
| `point_sqls.py` | `query_cd_statistics` | 测点统计信息 |
| `point_sqls.py` | `query_yb_info` | 测点异常信息 |

### 5. `utils/aqjc_utils/data_dictionary.py` + `NAO_AQJC_tables_desc.yaml`

- yaml 定义 **17 张 ClickHouse 表**的结构（表→字段→中文描述），按前缀分 6 类：

| 前缀 | 业务 | 表（时间粒度）|
|---|---|---|
| `FZDY` | 分站基本信息 | `ODS_AQJK_FZDY_1D` / `_30D` / `_2Y` |
| `FZSS` | 分站实时数据 | `ODS_AQJK_FZSS_1D` / `_30D` / `_2Y` |
| `CDDY` | 测点基本信息 | `ODS_AQJK_CDDY_1D` / `_30D` / `_2Y` |
| `CDSS` | 测点实时数据 | `ODS_AQJK_CDSS_1D` / `_30D` / `_2Y` |
| `TJSJ` | 测点统计信息 | `ODS_AQJK_TJSJ_1D` / `_30D` / `_2Y` |
| `YCBJ` | 测点异常信息 | `ODS_AQJK_YCBJ_30D` / `_2Y` |

- `data_dictionary.py` 提供 `load_tables_desc()` / `get_table_desc(name)` / `list_tables()`，带缓存只读一次。
- 注意 `utils/` 根下还有一份相同内容的 yaml 副本。

## 四、`test_aqjc/` —— 独立 Agent 客户端示例

**不是 MCP 服务端的一部分**，而是演示"把本 MCP 当工具源，用 LLM Agent 调用"的客户端样例：

- `demo_stream.py`：用 `langchain_mcp_adapters` 的 `MultiServerMCPClient` 连 `http://10.11.3.210:7666/mcp`，
  配 LangGraph StateGraph，模型 `openai:qwen3.6-27b`（base_url `http://10.11.3.210:9701/v1`），`build_agent` 构建可调用工具链的 Agent。
- `agent_service.py`：FastAPI 服务，支持流式（`StreamingResponse`）和一次性请求，CORS 中间件，滚动日志。
- `agent_gradio.py`：Gradio Chat 界面（流式 + 一次性）。

### 运行（可选，独立于 MCP 服务）

```bash
cd /home/user/公共/shihy/Nao_mcp/test_aqjc
python agent_service.py    # FastAPI + Gradio，需先确保 MCP 服务在 7666 端口运行
```

## 七、维护提示

1. **改工具**：改 `aqjc_tool.py` 对应 `_register_*_tool` 方法；改 schema 字段名时同步更新
   `docs://aqjc/data-dictionary` resource 文本与配套 skill 里的字段列表。
2. **改表结构**：更新两份 `NAO_AQJC_tables_desc.yaml`（`utils/aqjc_utils/` 与 `utils/` 根下，内容需一致）。
3. **改 SQL**：在 `sqls/AQJC_sqls/` 对应文件改，函数名变化时同步 `sqls/AQJC_sqls/__init__.py` 导出。
4. **日志**：服务日志 `logs/AQJC_service.log`（RotatingFile 50MB×5）；MCP 协议层日志也在其中（FastMCP 自带）。
5. **安全**：`main_AQJC.py` 里硬编码了 ClickHouse 账号密码，生产环境建议改为环境变量/配置注入。
